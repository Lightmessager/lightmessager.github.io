## [GaussianReadPro]({{ '/portfolio/gaussian-log-reader-pro/' | relative_url }})

A desktop workbench for reading Gaussian output files and building auditable reaction energy profiles.

- **Import and inspect:** batch-read Gaussian log files and trace extracted energies to their source jobs.
- **Compare pathways:** define relative-energy expressions and reference systems, then explore interactive 2D and 3D reaction profiles.
- **Save and share:** restore projects and export chart images, standalone HTML, data tables and source-audit information.
- **Work locally:** Chinese and English interfaces, with chart resources bundled for offline use.

[Download Windows preview](https://github.com/Lightmessager/Gaussian09d-log-reader-Pro/releases/latest) · [Project details]({{ '/portfolio/gaussian-log-reader-pro/' | relative_url }}) · [Source code](https://github.com/Lightmessager/Gaussian09d-log-reader-Pro)

The current preview targets Windows 11 x64. Extract the complete portable package and run `GaussianReadPro/GaussianReadPro.exe`.
