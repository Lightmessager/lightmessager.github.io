## [Gaussian LogReader Pro]({{ '/portfolio/gaussian-log-reader-pro/' | relative_url }})

A desktop tool for extracting thermodynamic data from Gaussian log files, calculating relative energies and plotting reaction profiles.

I defined the feature set, data layout and interaction model around my own post-processing workflow. **Implementation: Tencent Hy4preview.**
