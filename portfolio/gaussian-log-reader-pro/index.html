GaussianReaderPro

Gaussian output analysis and reaction energy profiles
Download Windows preview · Source code and documentation

Motivation

Comparing Gaussian calculations involves extracting energies and thermal corrections, choosing consistent references and keeping track of the original outputs. I designed the original tool around the repetitive copying and expression-building steps in my own workflow.

Current Workbench

GaussianReaderPro uses a Python and Qt interface to organise calculations by source file and job. It supports Chinese and English, with chart resources bundled for offline operation.

  • Batch-import Gaussian log files and inspect parsed energies alongside their source evidence.
  • Build relative-energy expressions for individual structures and define explicit reference systems.
  • Explore interactive 2D and 3D reaction energy profiles, compare paths and inspect selected structures.
  • Save and restore projects and related application state.
  • Export chart images, standalone HTML, data tables and source-audit information.

Download and Run

The current portable preview targets Windows 11 x64. Open the latest release, download the Windows ZIP, and extract the complete package. Run GaussianReaderPro/GaussianReaderPro.exe while keeping the bundled _internal directory in place.

Source development currently targets Python 3.12 and PySide6. Setup and build instructions are in the repository README.

Scientific Use

Check extracted values and species assignments against the original Gaussian outputs. Energy comparisons require consistent calculation settings, thermal corrections and stoichiometry. Source-audit exports help retain the evidence behind a reaction profile.

Project Origins

My contribution to the original tool included workflow problem identification, feature requirements, data layout and interface interaction design. The current repository contains the Qt-based GaussianReaderPro workbench and its source, tests, packaging scripts and documentation.

An earlier Gaussian09 extraction script is also available. My programming background is described in my CV.
